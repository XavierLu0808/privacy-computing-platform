# 隐私计算平台控制台 · 前端站

原设计稿（`../隐私计算平台控制台演示 – 控制台演示 · 五大模块（可操作）.html`）是 dc-runtime 打包产物，数据全在页面里写死。本目录把它重写成可部署的原生静态站：**所有数据都走 `API.md` 定义的接口**，后端未就绪时由浏览器内的 mock 顶上。

## 跑起来

无构建步骤，任意静态服务器即可：

```bash
cd web
python3 -m http.server 8412 --bind 127.0.0.1
# 打开 http://127.0.0.1:8412
```

换 nginx / caddy 直接把本目录设成站点根目录，无需其他配置。

## 测试

mock 后端的接口契约测试（Node ≥ 20，无依赖）：

```bash
cd web
node --test tests/*.test.mjs
```

覆盖：任务类型目录、任务列表播种与过滤、新建任务 9 类校验、自定义模型上传、时序任务全流程（启动 → 每轮 RMSE/MAE → Success → CSV 列）、分类任务兼容字段、数据接入（7 类校验 / 接入中→就绪 / 重名 / 文件来源 / 脱敏预览 / 删除）、求交流水线（5 类校验 / 统计量来自所选数据集 / 完成后生成 FL 任务）。

## 接真后端

改 `js/config.js` 两行：

```js
window.APP_CONFIG = {
  apiBase: 'https://your-host/api/v1',
  useMock: false,        // ← 关掉 mock
  accessToken: '<token>',
  mockLatencyMs: 80
};
```

业务代码一行都不用动：`js/api.js` 在 `useMock: false` 时改用 `fetch` + `EventSource`，请求路径、请求体、响应解析与 mock 模式完全一致。

## 与 API.md 的对应关系

前端调用的每个接口都能在 `../API.md` 找到，编号即该文档「接口总表」的行号：

- 公共：`/me`、`/platform/info`、`/projects`、`/files`
- 联邦学习：任务类型目录、任务列表 / 新建、任务详情 / 动作 / 指标 / 节点 / 公钥 / CSV 导出 / SSE
- 同态加密：`/he/schemes`、`/he/keys`、`/he/encrypt`、`/he/evaluate`、`/he/decrypt`
- MPC：`/mpc/estimate`、任务创建 / 动作 / 详情 / 历史 / 导出 / SSE
- 数据接入（v1.1）：`/psi/parties`、数据集列表 / 接入 / 详情 / 删除
- PSI：`/psi/protocols`、模板 CRUD、流水线创建 / 详情 / 取消 / SSE
- DP：配置读写、`/dp/estimate`、预算、审计

## mock 与真后端的已知差异

1. **导出格式**：`API.md` 里 MPC 报表默认 `xlsx`，mock 只生成 CSV（浏览器里造 xlsx 不值当）。真后端按文档返回 xlsx 即可，前端走 `window.open` 不受影响。
2. **状态不持久**：mock 数据存在内存，刷新页面即回到初始态。
3. **仿真数值**：训练曲线、密文耗时、通信量沿用原设计稿的公式，保证演示手感一致，不代表真实性能。
