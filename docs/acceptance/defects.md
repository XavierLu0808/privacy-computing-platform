## 严重（2 条）

### D01 [FL-AGG-02 / FL-AGG-06 / FL-ORCH-04（全局）] 刷新浏览器后所有新建 / 保存的数据丢失

- 复现步骤：任一页面保存配置（如聚合与安全把掩码轮换周期改为 20 并「保存到项目」，或任务编排新建项目）→ 浏览器刷新
- 实际：回到平台默认值，新建的项目 p4 / p5 消失，页头显示「尚未保存」；mock 数据只在内存中
- 预期：FL-AGG-02 预期「刷新页面后保持」；FL-ORCH-04 要求项目配置持久化存储。mock 层应至少用 localStorage 持久化，或在验收说明中写明仅接真实后端时持久化

### D02 [FL-EVAL-01 / 02 / 03] 合同技术指标评估结果为前端仿真数值，非真实运行

- 复现步骤：联邦学习 → 技术指标验证 → 任一卡片「开始评估」；对照 docs/acceptance/fed-sec.json 的 impl / status

- 预期：合同 T-01 / T-02 需要真实评估引擎运行（或提供离线真实实验记录与可复现脚本），界面结果应注明数据来源
