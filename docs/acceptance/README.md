# 需求与验收源资料

`items.json` 定义固定功能编号及合同映射；原始 DOCX/XLSX 是需求依据。模块 JSON 保留早期页面、操作、接口与实现映射，其中的 Mock 行为、测试路径和 `status: done` 属于历史记录，不表示当前前后端验收通过。

当前测试结果、浏览器记录、截图和报告应重新生成，默认不提交 Git。旧 Mock 的 `e2e-results.json`、缺陷汇总、截图和衍生手册/报告已经清除，可从 Git 历史查阅。

使用方式见[文档索引](../README.md)和[前端 README](../../README.md)。证据工具只认可范围与当前源码摘要匹配的测试或浏览器记录；不自动将历史实现映射升级为通过结果。
